1. Objectifs#

  • Échantillonner des caractéristiques résidentielles cohérentes (EUEMr 2022).
  • Utiliser un réseau bayésien pour capturer dépendances entre variables.
  • Ajouter variables exogènes (hors BN).
  • Mapper vers un format HPXML standard.
  • Fournir une UI pour inspection & export CSV.

Bénéfices

  • Génération reproductible & contrôlable.
  • Intégration prête pour pipeline simulation énergie.
  • Extensible (ajout de noeuds, mappings, validations).

Le mapping normalise les champs internes vers les paramètres attendus par moteurs ou pipelines HPXML.

  • Correspondance clé interne → balise HPXML

  • Préparation export batch

7. Exemples Code#

# Chargement BN
sampler = Sampler()
sampler.Load_BN("data/processed/bayesian_network/BN_EUEMr.XDSL")

# Evidence (optionnel)
evidence = {
    # "Type_Logement": "Maison en rangee",
    # "Nombre_Pieces": "1"
}

# Échantillonnage
df_bn = sampler.do_Sampling(200, evs=evidence)

# Variables hors BN
bba = BuildstockBatchArguments()
ext_vars = bba.sampling(df_bn.to_dict("records"))
merged = [{**e, **b} for e, b in zip(ext_vars, df_bn.to_dict("records"))]

# Mapping HPXML
mapper = MapHPXML()
mapped = mapper.run(merged)
